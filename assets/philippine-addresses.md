# Philippine checkout addresses

Location names come from the [Philippine Statistics Authority's Philippine Standard Geographic Code](https://psa.gov.ph/classification/psgc). The JSON was derived from the [2026-Q2 ph-psgc snapshot](https://github.com/Tenasia/ph-psgc/tree/2026-Q2/psgc), with the PSA's 2026-Q3 correction from Lambangan to Lambagan in Cabanglasan, Bukidnon.

The storefront uses names only, with Metro Manila grouped as one area and independent cities elsewhere grouped separately. Manila's district names are included alongside its barangay names to aid selection. The directory contains 1,642 cities and municipalities and 42,010 barangays. No map coordinates are included.
